3. How I Built It

พัฒนางานนี้โดยประยุกต์ใช้กระบวนการ Issue-driven workflow ร่วมกับ Git/GitHub และ Bootstrap 5 ตามขั้นตอนดังนี้:

  1. สร้าง Issues บน GitHub เพื่อวางแผนการทำงานและติดตามทีละส่วน
  2. เชื่อมโยง Bootstrap 5 CDN เข้าสู่ระบบ HTML
  3. จัดโครงสร้าง Layout ใหม่ด้วย Bootstrap Grid System (`container`, `row`, `col-*`)
  4. ทดสอบการแสดงผลแบบ Responsive บนหน้าจอคอมพิวเตอร์ แท็บเล็ต และมือถือ
  5. Commit และ Push โค้ดขึ้น GitHub เพื่อ Deploy บน GitHub Pages

4. Overall Reflection

  • ปัญหาหรือความท้าทายที่พบ: การทำความเข้าใจ Bootstrap Grid System และการจัดสรร Relative Path ของรูปภาพให้ถูกต้องตามโครงสร้างไดเรกทอรี
  • สิ่งที่ได้เรียนรู้: เรียนรู้การจัดวางเว็บไซต์ให้รองรับทุกอุปกรณ์ด้วย Responsive Framework และเข้าใจการบริหารจัดการโค้ดแบบ Issue-driven บน GitHub
  • การพัฒนางานในอนาคต: อยากเพิ่มลูกเล่น Dark Mode, Animations และพัฒนาโครงสร้างเว็บให้ดึงข้อมูลแบบ Dynamic ต่อไป
